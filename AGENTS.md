# Level design rules

For new or revised caves, read `docs/LEVELDESIGN-REGELN.md` before editing maps. Include a design brief, a comparison with nearby caves, a successful timed replay and tests that try to bypass each claimed mandatory action. Preserve historical map definitions for pending offline runs; reset records by map hash only for changed caves. Do not use map area, gem count or a passing solution replay as evidence of distinct or engaging gameplay. Report automated timing separately from human feedback.
